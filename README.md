# domarovdom — Personal Site

Modern responsive personal portfolio. Static HTML/CSS/JS, no build step required.

## Publish with GitHub Pages

Repository: `domarovdom/MyWeb`

In GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

The site will then be available at `https://domarovdom.github.io/MyWeb/` once Pages finishes deploying.
